# Voice Translator AI

Android app for voice recognition + translation + multilingual TTS.

## Features
- Speak audio input
- Translate between languages
- Play translated output using system TTS
- Male/female voice selection
- Marathi, Hindi, English and more locales

## Run locally
1. Open the project in Android Studio
2. Sync Gradle
3. Install on emulator or device

Optional CLI:

```bash
./gradlew assembleDebug
```
